💻 أساسيات تقنية الواجهة الأمامية (HTML / CSS / JavaScript)

الصف الثاني الثانوي — منهج البرمجة والذكاء الاصطناعي (الكتاب المدرسي + كتاب التقييمات)

📝 أولاً: أسئلة الاختيار من متعدد 20 سؤالاً
1. ما اللغة الأساسية المُستخدمة لتحديد البنية والتركيب الهيكلي لصفحة الويب (مثل العناوين والفقرات والروابط)؟
أ) CSS
ب) HTML
ج) JavaScript
د) SQL
✔ الإجابة الصحيحة: ب) HTML (تحدد البنية والتركيب الهيكلي لصفحة الويب)
2. ما التقنية المسؤولة عن تنسيق المظهر البصري لصفحة الويب مثل الألوان والخطوط والأبعاد والتخطيط؟
أ) HTML
ب) CSS
ج) JavaScript
د) JSON
✔ الإجابة الصحيحة: ب) CSS (تُستخدم لتحديد المظهر البصري والتنسيق)
3. أي من اللغات التالية تُضيف السلوك التفاعلي والاستجابة الحية لأحداث المستخدم في الواجهة الأمامية؟
أ) HTML
ب) CSS
ج) JavaScript
د) PHP
✔ الإجابة الصحيحة: ج) JavaScript (تُضيف السلوك التفاعلي والوظائف الديناميكية)
4. أي من عناصر HTML الداللية (Semantic HTML) يُستخدم لتحديد القسم الرئيسي والمركز لمحتوى الصفحة؟
أ) <header>
ب) <footer>
ج) <main>
د) <nav>
✔ الإجابة الصحيحة: ج) <main> (يُستخدم دلالياً لتأطير المحتوى الرئيسي المباشر)
5. العنصر الدلالي <nav> في لغة HTML يُستخدم مخصصاً لـ:
أ) رأس الصفحة العلوي
ب) تذييل أسفل الصفحة
ج) التنقل بين أجزاء وصفحات الموقع
د) المحتوى التفاعلي
✔ الإجابة الصحيحة: ج) التنقل بين أجزاء وصفحات الموقع
6. أي مما يلي لا يُعتبر من عناصر HTML الداللية (Semantic HTML)؟
أ) <header>
ب) <E-mail>
ج) <main>
د) <footer>
✔ الإجابة الصحيحة: ب) <E-mail> (ليس وسماً رسمياً في HTML الداللية)
7. ما المقصود بمفهوم التصميم المتجاوب (Responsive Design) في تطبيقات الويب؟
أ) جعل الصفحة تعمل فقط على الكمبيوتر
ب) ضبط وتكييف التخطيط تلقائياً وفقاً لأحجام الشاشات المختلفة
ج) استخدام JavaScript فقط للتفاعل
د) تحسين سرعة معالجة الخادم
✔ الإجابة الصحيحة: ب) ضبط وتكييف التخطيط تلقائياً وفقاً لأحجام الشاشات المختلفة
8. النهج التصميمي الذي يبدأ بإنشاء التخطيط للشاشات الصغيرة (مثل الهواتف) أولاً ثم التوسع للشاشات الكبيرة يُعرف بـ:
أ) نهج الأولوية للجوال (Mobile-First)
ب) التصميم الخطائي
ج) التكييف المباشر
د) العرض المتوازي
✔ الإجابة الصحيحة: أ) نهج الأولوية للجوال (Mobile-First)
9. أي من الخيارات التالية لا يُعد معلومة مناسبة إلدراجها أو فائدة لاستخدام HTML الداللية؟
أ) مساعدة قارئات الشاشة لذوي الإعاقة
ب) مساعدة محركات البحث SEO في فهم البنية
ج) زيادة سرعة عرض الصفحة بالضرورة تلقائياً
د) توضيح معنى ووظيفة أجزاء الصفحة
✔ الإجابة الصحيحة: ج) زيادة سرعة عرض الصفحة بالضرورة تلقائياً (HTML الداللية توضح البنية والمعنى وليس السرعة الفيزيائية)
10. مكتبة JavaScript المخصصة لبناء واجهات المستخدم من مكونات قابلة لإعادة الاستخدام (Reusable Components) هي:
أ) React
ب) HTML
ج) SQL
د) CSS
✔ الإجابة الصحيحة: أ) React (مكتبة لبناء واجهات المستخدم بمكونات قابلة لإعادة الاستخدام)
11. إطار العمل المتقدم المبني على مكتبة React والذي يوفر التوجيه (Routing) وطرق عرض الصفحات والعمل على الخادم والعميل هو:
أ) Next.js
ب) Vue
ج) CSS
د) HTML
✔ الإجابة الصحيحة: أ) Next.js (إطار عمل مبني على React)
12. أي من أطر العمل التالية يُعرف ببنيته البسيطة ويتيح بناء تطبيقات الويب تدريجياً بدءاً من ميزات صغيرة؟
أ) Next.js
ب) Vue
ج) React
د) Docker
✔ الإجابة الصحيحة: ب) Vue (إطار عمل يتيح بناء التطبيقات تدريجياً)
13. في تشبيه المبنى، إذا كانت HTML هي الهيكل العظمي للمبنى، فما التقنية التي تمثل الديكور الداخلي والتصميم؟
أ) JavaScript
ب) CSS
ج) API
د) JSON
✔ الإجابة الصحيحة: ب) CSS
14. في تشبيه المبنى، التقنية التي تمثل شبكات التوصيل التفاعلية والكهرباء والأنظمة الذكية داخل المبنى هي:
أ) HTML
ب) CSS
ج) JavaScript
د) SQL
✔ الإجابة الصحيحة: ج) JavaScript
15. العنصر <footer> في لغة HTML الداللية يُستخدم لتعريف:
أ) المحتوى الرئيسي للمستند
ب) تذييل أسفل الصفحة (مثل حقوق النشر والروابط)
ج) رأس الصفحة العلوي
د) شريط التنقل الجانبي
✔ الإجابة الصحيحة: ب) تذييل أسفل الصفحة (عرض التذييل في أسفل الصفحة)
16. ما المصطلح المعتمد لقياس الممارسات التي تجعل صفحة الويب أسهل في الفهرسة والظهور في نتائج البحث؟
أ) SEO (تحسين محركات البحث)
ب) Accessibility (إمكانية الوصول)
ج) API Integration
د) TLS Encryption
✔ الإجابة الصحيحة: أ) SEO (Search Engine Optimization)
17. مفهوم إمكانية الوصول (Accessibility) يهدف بالأساس إلى:
أ) تسريع استجابة الخادم
ب) تصميم المحتوى والواجهة ليتمكن ذوو القدرات والاحتياجات المختلفة (بمن فيهم ذوو الإعاقة) من استخدامها
ج) تقليل ألوان الصفحة لتوفير الطاقة
د) التشفير بالمفتاح العام
✔ الإجابة الصحيحة: ب) تصميم المحتوى والواجهة ليتمكن ذوو القدرات والاحتياجات المختلفة من استخدامها
18. الخيار الذي يصف إطار العمل (Framework) بأفضل شكل في الواجهة الأمامية هو:
أ) لغة لتحديد بنية صفحة الويب
ب) بنية تجعل تطوير تطبيقات الويب أكثر كفاءة وإعادة استخدام المكونات
ج) تقنية لتشفير البيانات وإرسالها بأمان
د) مفهوم تصميمي لدعم الشاشات
✔ الإجابة الصحيحة: ب) بنية تجعل تطوير تطبيقات الويب أكثر كفاءة وإعادة استخدام المكونات
19. تحديث جزء صغير فقط من الشاشة (مثل زيادة عداد التسجيل أو الإعجابات) دون إعادة تحميل الصفحة بالكامل هي وظيفة:
أ) HTML
ب) CSS
ج) JavaScript
د) SQL
✔ الإجابة الصحيحة: ج) JavaScript
20. الاختصارات الرسمية للتقنيات الثلاث (البنية، المظهر، السلوك) على التوالي هي:
أ) HTML / CSS / JavaScript
ب) HTTP / TLS / JSON
ج) API / SQL / React
د) SEO / XAI / Vue
✔ الإجابة الصحيحة: أ) HTML (البنية) / CSS (المظهر) / JavaScript (السلوك)
✍️ ثانياً: الأسئلة المقالية والتحليلية 15 سؤالاً
س1: اشرح بالتفصيل الأدوار المميزة والتكامل بين تقنيات الواجهة الأمامية الثلاث (HTML, CSS, JavaScript) في بناء صفحة ويب متكاملة.
الإجابة النموذجية:
• HTML (البنية): تحدد الهيكل والتركيب الأساسي للصفحة (مثل العناوين، الفقرات، الصور، الروابط، ونماذج الإدخال)، وتشبه الهيكل العظمي للمبنى.
• CSS (المظهر): تُحدد المظهر البصري والتنسيق (الألوان، نوع الخطوط، الحجم، الأبعاد، وتوزيع العناصر والتخطيط المتجاوب)، وتشبه التصميم الداخلي والديكور.
• JavaScript (السلوك): تضيف الوظائف السلوكية والتفاعلية الحية (مثل التحقق من مدخلات النموذج، تصفية البيانات فورياً، وتحديث أجزاء من الشاشة دون إعادة تحميل الصفحة)، وتشبه الأنظمة التفاعلية والكهرباء بالمبنى.
س2: لماذا تُعتبر لغة HTML الداللية (Semantic HTML) مهمة في بناء الواجهات الحديثة؟ اذكر مثالين لعناصر داللية مع توضيح وظيفتهما.
الإجابة النموذجية:
تُعتبر HTML الداللية مهمة لأنها تستخدم وسوماً تصف بوضوح معنى ووظيفة المحتوى الموجود بداخلها بدلاً من الوسوم العامة، مما يساعد المتصفحات والتقنيات المساعدة ومحركات البحث على فهم هيكل الصفحة.
• أمثلة لعناصر داللية:
1. <header>: يُحدد رأس الصفحة أو رأس القسم العلوي.
2. <main>: يُحدد المحتوى الرئيسي والمركز للصفحة.
3. <nav>: يُحدد أجزاء وروابط التنقل الرئيسية بالصفحة.
4. <footer>: يُحدد تذييل أسفل الصفحة (حقوق النشر والمعلومات التكميلية).
س3: وضح كيف يُسهم استخدام عناصر HTML الداللية في تحسين كل من: (أ) محركات البحث SEO، (ب) إمكانية الوصول Accessibility.
الإجابة النموذجية:
• أ) محركات البحث (SEO): تُمكن عناكب ومحركات البحث من قراءة وفهرسة أجزاء الموقع بفاعلية وفهم العناوين والمحتوى الرئيسي وتصنيف الصفحة بدقة في نتائج البحث.
• ب) إمكانية الوصول (Accessibility): تُساعد برامج قارئ الشاشة (Screen Readers) الخاصة بالمستخدمين ذوي الإعاقة البصرية على التعرّف على بنية الصفحة وتخطي الروابط للوصول المباشر للمحتوى الرئيسي عبر الوسم <main>.
س4: عرف مفهوم التصميم المتجاوب (Responsive Design)، واشرح كيف يُحسن تجربة المستخدم عبر الشاشات المختلفة.
الإجابة النموذجية:
• التعريف: هو مفهوم تصميمي يتم فيه ضبط وتكييف تخطيط صفحة الويب وأبعاد عناصرها تلقائياً وفقاً لحجم الشاشة المستعملة (هاتف، لوحي، كمبيوتر).
• تحسين تجربة المستخدم: يمنع الحاجة للتمرير الأفقي المجهد أو التكبير والتصغير اليدوي، ويعيد ترتيب العناصر والخطوط والصور لتناسب مساحة العرض المتاحة في الأجهزة المختلفة.
س5: اشرح نهج "الأولوية للجوال (Mobile-First)" في التصميم المتجاوب، ولماذا يُفضل البدء به أثناء تطوير تطبيقات الويب؟
الإجابة النموذجية:
• المفهوم: هو نهج يبدأ فيه المطور بتصميم الواجهة للشاشات الصغيرة (مثل الهواتف الذكية) أولاً، ثم التوسع تدريجياً وإضافة التنسيقات للشاشات الأكبر.
• سبب التفضيل: يفرض على الفريق التركيز على المحتوى والوظائف الأكثر أهمية وجوهرية للمستخدم دون تشتيت، بالإضافة إلى كون غالبية زوار تطبيقات الويب الحديثة يستخدمون الهواتف المحمولة.
س6: ما الفائدة من استخدام إطار عمل (Framework) أو مكتبة في تطوير الواجهة الأمامية مقارنة بكتابة الكود التقليدي؟
الإجابة النموذجية:
• يُلغي الحاجة لكتابة كافة الأكواد والوظائف التكرارية من الصفر.
• يوفر هيكلية جاهزة ومكونات برمجية قابلة لإعادة الاستخدام (Reusable Components).
• يسرّع عملية التطوير، ويزيد كفاءة وجودة الكود وسهولة صيانته وتطويره بواسطة فرق العمل.
س7: قارن بين مكتبة React وإطار العمل Next.js من حيث الخصائص والأهداف الأساسية في تطوير الواجهة الأمامية.
الإجابة النموذجية:
• مكتبة React: هي مكتبة JavaScript مخصصة لبناء واجهات المستخدم وتعتمد على تقسيم الصفحة إلى مكونات مستقلة قابلة لإعادة الاستخدام.
• إطار Next.js: هو إطار عمل كامل مبني على مكتبة React، يوفر ميزات متقدمة مثل التوجيه التلقائي (Routing)، وطرق عرض مختلفة للصفحات (Server-Side & Client-Side Rendering) لزيادة السرعة وتحسين SEO.
س8: وضح بمثال عملي كيف تتكامل التقنيات الثلاث (HTML, CSS, JS) في صفحة موقع مكتبة تعرض قائمة كتب وتتيح التصفية الفورية.
الإجابة النموذجية:
• HTML: تُنشئ بنية القائمة وعناوين الكتب وصورها ومربع نص البحث باستخدام عناصر هيكلية وداللية.
• CSS: تُنسق مظهر غلاف الكتاب، والألوان، وترتب الكتب في شبكة منتظمة وتضمن تجاوبها مع أحجام الشاشات.
• JavaScript: تستمع لحدث الكتابة في مربع البحث وتُصفي قائمة الكتب المعروضة فورياً وتحدث الشاشة بدون إعادة تحميل الصفحة.
س9: ناقش العبارة التالية: "صفحة الويب الحديثة هي تركيبة متكاملة؛ فبدون البنية تفقد المعنى، وبدون التنسيق تفقد الجاذبية، وبدون السلوك تفقد التفاعلية".
الإجابة النموذجية:
تعبر العبارة عن الترابط الوثيق بين تقنيات الواجهة الأمامية:
• بدون HTML (البنية): لن يوجد محتوى أو عناصر أو معنى قابل للقراءة.
• بدون CSS (التنسيق): سيكون المحتوى خاماً وغير منظم وبدون ألوان أو تجاوب بصري جذب للمستخدم.
• بدون JavaScript (السلوك): ستكون الصفحة ثنائية الأبعاد وثابتة ولا تتفاعل حياً مع إجراءات المستخدم أو تحديثات البيانات.
س10: يريد موقع إخباري أن يعمل جيداً على الهواتف وأن تفهم محركات البحث بنية صفحاته؛ ما التوصية المناسبة في التصميم وHTML؟
الإجابة النموذجية:
• التوصية في التصميم: تطبيق **التصميم المتجاوب (Responsive Design)** ونهج **الأولوية للجوال (Mobile-First)** لتتعدل الخطوط والقوائم تلقائياً وفق حجم شاشة الهاتف.
• التوصية في HTML: استخدام **HTML الداللية (Semantic HTML)** وتحديد الأقسام بوسوم مثل <header> و <main> و <article> ليفهم محرك البحث هيكل الخبر ومحتواه الرئيسي.
س11: ما الفارق الأساسي بين إطار العمل Vue ومكتبة React بحسب ما ورد في المنهج؟
الإجابة النموذجية:
• React: مكتبة ت专注于 بناء واجهات المستخدم عبر مكونات قابلة لإعادة الاستخدام.
• Vue: إطار عمل يتميز ببنيته البسيطة ويتيح بناء تطبيقات الويب تدريجياً بدءاً من ميزات صغيرة وحتى التطبيقات الكاملة.
س12: في نشاط "فكر كمهندس": يريد نادٍ طالبي صفحة ويب تعرض الفعاليات، منسقة بألوان النادي، وتضم زراً لعدد المسجلين؛ وزّع هذه المهام على التقنيات الثلاث.
الإجابة النموذجية:
1. قائمة الفعاليات: تقع على عاتق HTML لأنها البنية الهيكلية التي تحمل محتوى الفعاليات والعناوين.
2. ألوان النادي وتخطيط الصفحة: تقع على عاتق CSS لأنها المسؤولة عن تنسيق المظهر والألوان.
3. عداد التسجيل الحي: يقع على عاتق JavaScript لأنه يُضيف السلوك والتفاعل الحي والتحديث عند الضغط.
س13: علل: يُفضل المطورون فصل ملفات HTML و CSS و JavaScript في تطوير المشاريع الحقيقية بدلاً من كتابتها في ملف واحد.
الإجابة النموذجية:
• فصل الاهتمامات (Separation of Concerns): يضمن سهولة الصيانة وقراءة الكود وتعديله.
• إعادة الاستخدام والتطوير: يسمح بربط ملف التنسيق CSS أو الجافاسكريبت بعدة صفحات، وتوزيع العمل بين أعضاء الفريق بفاعلية.
س14: اشرح كيف يُعالج إطار العمل Next.js تحدي تحسين محركات البحث (SEO) في تطبيقات الويب المبنية بـ React.
الإجابة النموذجية:
يوفر Next.js خاصية العرض من جانب الخادم (Server-Side Rendering)، حيث يقوم بتجهيز صفحة HTML مكتملة البنية والمحتوى في الخادم وإرسالها للمتصفح جاهزة، مما يسمح لعناكب محركات البحث بقرائتها وفهرستها بسهولة.
س15: بصفتك مطور واجهات، صمم هيكلاً أولياً لصفحة تطبيق مدرسي متكامل يراعي البنية المعنوية والتجاوب والتفاعلية.
الإجابة النموذجية:
• البنية المعنوية (HTML): استخدام <header> لشعار المدرسة، و <nav> للقائمة، و <main> للأخبار والجدول الدراسي، و <footer> للتواصل.
• التكيف والتجاوب (CSS): إعداد تخطيط متجاوب بنهج Mobile-First يغير ترتيب الأقسام على الهاتف لتصبح قائمة رأسية مرنة.
• التفاعلية (JavaScript): إضافة زر لإظهار الإشعارات المدرسية فورياً والتحقق من صحة بيانات نموذج التواصل.
